Proyecto personal · en desarrollo

MagicInventory

Aplicación de inventario para colecciones de cartas de Magic: The Gathering, pensada para adaptarse a otros tipos de colección. Cada usuario tiene su propia colección en la nube, con stock, categorías, imágenes y precios actualizados con la API de MKM.

  • Python
  • Firebase Auth
  • Firestore
  • MKM API

  • Registro e inicio de sesión con Firebase Authentication.

  • Colección independiente y persistente para cada usuario en Firestore.

  • Control de stock, categorías, imágenes y exportación de datos.

  • Seguimiento de precios de mercado con la API de MKM.

El código todavía no es público. Pronto añadiré capturas y el enlace al repositorio.
